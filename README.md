# MyDiet Tracker

Free offline-first Android-installable PWA.

## Install
1. Upload all files in this folder to a free static HTTPS host (GitHub Pages is one option).
2. Open the hosted URL in Chrome on Android.
3. Tap ⋮ → Install app / Add to Home screen.
4. Open once online so offline caching can complete.

## Features
- Daily calories, protein, carbs and fat
- Food search, custom foods and quantities
- Six-day diet plan with one-tap meal logging
- Offline rule-based diet assistant
- Local-only data and JSON backup/restore
- No account, subscription, ads, paid API or remote AI

Nutrition note: packaged values use the labels previously supplied for oats, Kutwal milk, sattu and curd. Other foods are estimates. Chapati assumes one piece made from about 40g dry atta. Add oil separately for accuracy. Your data stays in browser storage on this device; export backups regularly.
